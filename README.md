# 浮生 · 自动进化生态缸

[在线游玩](https://jensen-ai-dot.github.io/fusheng-idle-life/)

直接打开 index.html，或通过发布的网页游玩。无需安装、无需点击开始、没有声音。

- 200 种具名生命，10 个章节，每章 20 种。基础旅程约 8 小时，属性和事件会改变实际速度。
- 六维属性：体魄、灵巧、适应、感知、智慧、繁衍。分别影响产能、演化、研发费用等，并改变物种发现优先级与章节路线。初始 5 点，每发现 5 种生命获得 2 点。
- 三项生命技能：光合代谢、觅食本能、共生网络。消耗生命能量解锁和升级，最高 5 级，持续提高在线与离线生命能量获取。智慧最多降低 40% 研发费用。
- 8 类世界事件，每类 2 个选项。选择永久增减属性，同时添加有明确持续时间的产能与演化速度增减益。属性最低为 0。
- 世界事件按随机间隔和随机类型出现，无选择时间限制。当前事件会保留到手动决定，期间自动成长照常继续；处理后再随机等待下一次事件。
- 演化速度可选 0.5×、1×、2×、5×、10×，会保存到存档。倍率影响在线及离线的物种发现节奏；世界事件按实际时间推进。
- 能量自动产生、升级自动购买。生态缸内生物逐渐增加。
- 专注模式收起两侧面板；舒缓动效减慢画面，不改变成长速度。
- 暂停会同时停止在线与离线成长。再次点击继续恢复。
- 进度每 5 秒保存到当前浏览器，离线最多结算 8 小时。
- 更换电脑或清理浏览器前，可通过“存档管理”导出 JSON，再在新浏览器导入。
- 本地文件与发布网页各自存档。通过导出、导入可以转移。

这是想象中的生命观赏游戏，包含不同生命类群。200 个物种形象由内置 imagegen 生成，按十张 5×4 图集的固定格位映射到图鉴、详情和生态缸。画面使用柔和的发光合成，保留低频漂游动效，轮流展示各章代表。物种并非沿单一直线演变；路线、顺序与时间均为艺术演绎。

运行检查：`node --test tests.cjs`。
