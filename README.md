# 浮生 · 自动进化生态缸

[在线游玩](https://jensen-ai-dot.github.io/fusheng-idle-life/)

直接打开 index.html，或通过发布的网页游玩。无需安装、无需点击开始、没有声音。

- 全图鉴包含300种真实生命和40种原创幻想生命，共17个章节；所有形象可在图鉴详情中预览。
- 每轮只发展一条41步的演化路线：12步共同序章、24步真实分化、4步幻想新生与1个最终形态。基础约6.4小时；完成后继续产生能量，不再补走其他路线。
- 六维属性：体魄、灵巧、适应、感知、智慧、繁衍。首次分化依据最高属性锁定主线；同分按上述顺序决定。阶段进入时，具体形态按当时属性锁定，之后加点与事件影响未锁定阶段与最终结局。
- 主线有强壮巨兽、轻盈飞羽、逆境共生、深蓝探索、智慧新生、繁盛花园六种方向；终点不统一。界面显示锁定状态、锁定原因、下一分化预测及事件选项的预测影响。
- 初始5个属性点，每发现5种新的图鉴生命获得2点。历史物种不会重复奖励。
- 9项生命技能，全部最高Lv.12：光合代谢、觅食本能、共生网络、细胞呼吸、养分循环、能量储存、感官捕食、群体协作、逆境代谢。使用生命能量解锁升级，持续影响在线与离线产能。智慧最多降低40%费用。
- 11个真实纪元大事件按年代顺序，在对应演化进度解锁后随机来临，包括大氧化事件、成冰纪全球冰期、寒武纪大辐射、奥陶纪末/泥盆纪晚期/二叠纪末/三叠纪末/白垩纪末生物危机，以及森林、煤沼与哺乳动物扩张。历史卡片提供约略年代与NASA、NPS资料入口。每个历史事件仅出现一次；期间和结束后还会随机出现8类普通生态事件。
- 事件无选择倒计时，待处理期间挂机继续；选择永久改变属性，并带来限时增减益。处理后随机等待90–360秒再触发下一事件；未到历史进度时不会提前播放未来史事。属性最低为0。
- 演化速度可选0.5×、1×、2×、5×、10×。倍率影响在线及离线演化；事件间隔按实际时间推进。
- 能量自动产生、生态等级自动升至50级。生态缸仅展示本轮当前生物，进化后自动替换；历史图鉴与预览不会加入场景，支持专注模式、舒缓动效和暂停。
- 进度每5秒保存在当前浏览器，离线最多结算8小时。暂停同时停止在线与离线成长。存档管理可导出/导入JSON。
- 存档管理新增“重新开始”，二次确认后清空图鉴、能量、属性、技能及路线，恢复5属性点与1×速度，从初始细胞开启新旅程；可取消或先导出存档。
- 旧版存档保留年龄、资源、属性、技能和全部历史发现，并从迁移时开始新的41步旅程；旧图鉴作为档案保留。无需清空浏览器。

这是生命形态的艺术之旅，相邻具名物种并非直接祖先和后代。幻想生物原创；历史背景与游戏属性、增减益效果分别标注。340种形象使用17张imagegen生成的5×4透明图集，固定格位映射到图鉴和生态缸。

验证：`node --test tests.cjs`（包括lineage.test.cjs）。
